Bar-kassa

De kassa draait op een eigen server in het gebouw. Om de camera te mogen gebruiken (QR-kaarten scannen) heeft je telefoon een beveiligde verbinding nodig. Daarvoor installeer je eenmalig het certificaat van deze server.

1. Certificaat downloaden Certificaat downloaden
2. Certificaat vertrouwen

iPhone / iPad (open deze pagina in Safari)

  1. Tik op Toestaan om het profiel te downloaden.
  2. Ga naar Instellingen → Profiel gedownload → Installeer.
  3. Ga naar Instellingen → Algemeen → Info → Certificaatvertrouwen en zet Caddy Local Authority aan.

Android

  1. Ga naar Instellingen → Beveiliging → Meer → Certificaat installeren → CA-certificaat (de naam verschilt per telefoon; zoek in Instellingen op "certificaat").
  2. Kies het gedownloade bestand kassa-certificaat.crt.
3. Kassa openen Naar de kassa

Zet de kassa daarna op je beginscherm (Delen of menu → Zet op beginscherm), dan opent hij als een app.
