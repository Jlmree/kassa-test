# Bar-kassa

Een eenvoudig kassasysteem voor een bar of vereniging, in één HTML-bestand. Werkt op telefoon, tablet en computer, ook zonder server.

## Gebruiken

Open `index.html` in een browser. Of zet GitHub Pages aan voor deze repository (Settings → Pages → branch kiezen, map `/`), dan staat de kassa online.

## Wat kan het

- **Kassa**: producten per categorie aantikken, bestelling afrekenen met contant (met wisselgeld), pin, kaart of op rekening.
- **Rekeningen**: open rekeningen op naam, later bijbestellen en afrekenen.
- **Kaarten**: tegoedkaarten met QR-code aanmaken en printen, opwaarderen, scannen met de camera, blokkeren.
- **Dag**: dagoverzicht met omzet, per betaalmethode, per product, alle bonnen (annuleren mogelijk) en CSV-export.
- **Menu**: producten, prijzen en categorieën beheren, naam op de bon instellen.
- Bonnen delen, printen of als PDF opslaan.

## Gegevens

Alles wordt opgeslagen in de browser (`localStorage`) op het apparaat waar je de kassa gebruikt. Maak regelmatig een back-up via **Kaarten → Back-up**; met dezelfde knop zet je die terug, ook op een ander apparaat.
